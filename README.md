# One More Stride

One More Stride is a Next.js App Router website for an equine rescue, rehabilitation, and training initiative based in Kildare, Ireland.

The current implementation recreates the approved visual mockup with a cream, navy, olive, and antique-gold editorial equestrian identity. It uses temporary mockup-derived imagery and local mock data until final brand assets, photography, horse details, contact details, and donation links are supplied.

## Stack

- Next.js
- TypeScript
- App Router
- Cloudflare Workers
- OpenNext
- Wrangler

## Commands

```bash
npm install
npm run dev
npm run build
npx opennextjs-cloudflare build
```
